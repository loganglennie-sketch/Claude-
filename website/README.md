# ElevateX Marketing website

Open `index.html` in a browser to preview.

## Edit with Claude Code
In Terminal:
    cd ~/Documents/elevatex-website
    claude
Then ask for changes, e.g. "add a page for Google ads".

## Put it live on Vercel
1. Install the CLI once: `npm i -g vercel`
2. In this folder run `vercel` (first time: log in, accept defaults), then `vercel --prod`.
3. Add your domain in the Vercel dashboard: Project → Settings → Domains.
